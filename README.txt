# El Show de Dario Alejandro — sitio web

## Archivos
- `index.html` — página principal.
- `styles.css` — diseño, colores, responsive y efectos.
- `script.js` — año automático y animación del ecualizador.
- `assets/` — carpeta preparada para imágenes, logo o favicon.

## Cómo subirlo al hosting
1. Descargá y descomprimí el ZIP.
2. Subí `index.html`, `styles.css`, `script.js` y la carpeta `assets` al directorio público de tu hosting (normalmente `public_html`).
3. No cambies los nombres de los archivos.
4. Abrí tu dominio.
